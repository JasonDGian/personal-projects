# 2. Project Goals

The project was started with the following goals.

## Restoration

* [ ] Restore the console to working condition.
* [ ] Clean the console thoroughly.
* [ ] Inspect the motherboard.
* [ ] Repair existing faults.
* [ ] Preserve original hardware where practical.

## Customization

* [ ] Replace / customize the shell.
* [ ] Customize buttons and other external components.
* [ ] Maintain the usability of the original console.
* [ ] Ensure all modifications remain mechanically reliable.

## Presentation

* [ ] Design a custom cardboard box inspired by the original packaging.
* [ ] Design a custom display stand.
* [ ] 3D print the final stand.
* [ ] Create a coherent visual identity between the console, box and stand.
